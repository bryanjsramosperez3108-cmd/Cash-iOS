# Cash iOS

Aplicacion de finanzas personales
desarrollada con SwiftUI para iPhone.

## Caracteristicas

- Control de ingresos y gastos
- Administracion de cuentas
- Transferencias bancarias
- Calendario financiero
- Analisis de ingresos y gastos
- Graficas financieras
- Copias de seguridad
- Recordatorios diarios
- Interfaz moderna para iOS

## Privacidad

Este repositorio contiene el codigo fuente
de Cash, no los datos financieros del usuario.
